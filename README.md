# Personal Finance Tracker

A modern, full-stack application for managing personal wealth and transaction tracking for personal use. This project follows a decoupled **Client-Server Architecture**, utilizing a high-performance React frontend and a robust .NET backend.

## 🚀 Key Features

*   **Financial Dashboard:** Real-time visualization of monthly income vs. expenses.
*   **Transaction Management:** Full CRUD operations for financial records with categorized tagging.
*   **Categorization:** Ability categorize transactions by sources of income or areas of expense.
*   **Data Integrity:** Server-side validation and precise decimal handling for financial accuracy.

## 🛠 Tech Stack

*   **Frontend:** React with **TypeScript**
*   **Build Tool:** **Vite**
*   **Backend:** **.NET** (RESTful API)
*   **Database:** **PostgreSQL**
